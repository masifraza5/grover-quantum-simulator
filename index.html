How Grover's Algorithm Works

1. Initialize: Start with the state |0...0⟩.
2. Hadamard: Create an equal superposition of all states.
3. Oracle: Flip the marked state's amplitude sign.
4. Diffusion: Reflect amplitudes about their mean.
5. Repeat: Each Grover iteration amplifies the target probability until it approaches its maximum.
